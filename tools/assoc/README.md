# Подготовка «Ассоциаций»

Скрипт считает рейтинги близости слов для игры. Запускается на компьютере
администратора, результат заливается в приватный бакет Supabase. В репозиторий
попадают только скрипт, список загаданных слов и стоп-лист: модель, словарь и
готовые рейтинги лежат вне git (см. `.gitignore`).

## Что нужно поставить

```
pip install navec pymorphy3 pymorphy3-dicts-ru wordfreq numpy
```

Модель Navec — 50 МБ, кладётся в `tools/assoc/model/`:

```
https://storage.yandexcloud.net/natasha-navec/packs/navec_hudlit_v1_12B_500K_300d_100q.tar
```

## Как пользоваться

```
python tools/assoc/prepare.py dict    # словарь существительных (40 000 слов)
python tools/assoc/prepare.py ranks   # рейтинги для слов из targets.txt
python tools/assoc/prepare.py check   # проверка: всё ли на месте
python tools/assoc/upload.py          # залить рейтинги в бакет assoc-ranks
```

Для заливки нужен секретный ключ проекта в переменной окружения:

```
$env:SUPABASE_SERVICE_KEY = "<секретный ключ из настроек проекта>"
```

Ключ в репозиторий не попадает и нигде не сохраняется.

## Файлы

| Файл | Что это | В git |
|---|---|---|
| `prepare.py` | сборка словаря и рейтингов | да |
| `upload.py` | заливка рейтингов в Supabase Storage | да |
| `targets.txt` | загаданные слова, по одному на день | да |
| `stopwords.txt` | грубые и обидные корни: такие слова не идут ни в словарь, ни в подсказки | да |
| `model/` | модель Navec, 50 МБ | нет |
| `dict.txt` | словарь существительных | нет |
| `out/` | готовые рейтинги, по файлу на слово (~200 КБ каждый) | нет |

## Как устроен рейтинг

Файл `out/<слово>.json.gz` — это `{ "word": "<загаданное>", "words": [...] }`,
где `words` — все слова словаря по убыванию близости. Место слова равно его
номеру в списке плюс один, поэтому само загаданное слово всегда стоит первым.
Близость — косинус между векторами Navec.

Сервер (Edge Function `word-of-day`) скачивает такой файл из бакета, держит его
в памяти и отвечает игроку только номером присланного слова. Ни загаданное
слово, ни список наружу не уходят, пока игра не закончена.

## Лицензии

- **Navec** (natasha/navec) — MIT. Модель `hudlit_v1_12B_500K_300d_100q`:
  500 тыс. слов, 300 измерений, обучена на корпусе художественной литературы.
- **pymorphy3** — MIT. Словари `pymorphy3-dicts-ru` собраны из OpenCorpora,
  данные под Creative Commons Attribution-Share Alike 3.0.
- **wordfreq** — MIT, используется для отбора самых частых слов.

Словарь и рейтинги — производное от этих данных, поэтому они остаются
внутренними файлами проекта и лежат в приватном бакете, а не в открытом
репозитории.
