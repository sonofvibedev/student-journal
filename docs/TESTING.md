# Тестирование

Тесты идут на отдельном проекте Supabase `student-journal-test` (ref в `.env.test`). Прод (`journal-24dmm2`) тестами не затрагивается: каждый скрипт начинается с `tools/test/guard.mjs` и останавливается, если цель — прод. Docker и WSL не нужны.

## Настройка (один раз)

1. `supabase login` (CLI должен быть выполнен вход в аккаунт организации).
2. `cp .env.test.example .env.test`: нужен только `TEST_PROJECT_REF`. Пароль тестовых аккаунтов и service-ключ тестового проекта скрипт добавит в `.env.test` сам (файл в `.gitignore`).

## Команды

| Команда | Что делает | Состояние |
|---|---|---|
| `npm run test:migrate` | применяет миграции репозитория к тесту (из временной папки, адрес прода в cron заменяется) | готово |
| `npm run test:reset` | пересоздаёт тестовые данные: маскированная копия прода и 28 аккаунтов `student01…28@journal-test.example`; пишет `docs/reports/test-copy.md` | готово |
| `npm run test:deploy` | выкладывает Edge Functions этапа 1 в тест (из временной папки, без Docker) | готово |
| `npm run test:db` | SQL-тесты прав: изоляция групп, pending, роли, преподаватели, сисадмин, техработы, легаси (115 проверок) | готово |
| `npm run test:e2e` | сквозные тесты: API (42 проверки: заявка, одобрение, вход по коду, «Это он»/«Не он»/«Это не я», блок после 5 кодов) и браузер (21 проверка: register.html → sysadmin.html → join.html на настоящих функциях и bseu.by; нужен Chromium Playwright, путь в `CHROME_PATH`) | готово |
| `npm run test:all` | migrate → reset → deploy → db → e2e с текущего состояния | готово |

## Что маскируется

Имена → «Студент NN» (NN по алфавиту прода), `telegramUsername` и Telegram-таблицы не копируются, комментарии к пропускам очищаются, логины и пароли прода не копируются (у всех тестовых аккаунтов один пароль из `.env.test`). Поля «форма обучения» в текущих данных нет.

## Ограничения

- `supabase db push` из корня репозитория запускать нельзя: `supabase/` привязана к проду. Используйте `test:migrate`.
- Миграция `20260927151800` в тестовой копии условная (в новом проекте нет `rls_auto_enable()`).
- Первый запуск в агентском режиме: CLI требует `--yes` для записи в хостинг. Скрипты передают его только вместе с тестовым ref.
