## Правило

- Справка нужна уважительному пропуску с датой и причиной (`cert_type`). Вид: «Больничный» → sick, «Освобождение» → exemption, «Заявление» → statement, «Справка» и прочее → other.
- Больничные студента подряд — одна справка: соседние даты связаны, если между ними нет учебного дня (дня с парами группы в `schedule_lessons`). Выходные и праздники разрывом не считаются.
- Исключение владельца: Ракитская (`st-1758300000013`) и Щигло (`st-1758300000024`) — один больничный 19.10–24.10, хотя 21.10 у группы были пары (пропусков в тот день не внесено). Зашито в миграции (`v_join`) и в `tools/certs-merge.mjs` (`JOIN`) только для них и только на 21.10.
- Освобождение, заявление, справка — одна справка на студента, вид и день.
- Все перенесённые справки: `status = 'received'` (все 74 пропуска были «сданы»), `received_at` — время внесения последнего из слитых пропусков, `open = false`, id `ce-m13-<md5>` (метка для отката).
- 14 уважительных пропусков без причины (Хотяшова 12, Поленышев 1, Сорокин 1) не тронуты: справки им не создаются.
